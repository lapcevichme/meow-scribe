# Демонстрация

**Видео:** [Google Drive](https://drive.google.com/drive/folders/1pJ6H2zaZ7F9Aie6crc3N3rVtT1odSDUV?usp=sharing) · копия в репозитории: [`MeowScribe_demo.mp4`](MeowScribe_demo.mp4) (2:31, 720×1600, субтитры вшиты, звук — в сцене воспроизведения).

Записано на эмуляторе Android Studio x86_64 с 4 ГБ RAM, как у жюри. Интернета приложению не нужно: разрешения `INTERNET` в сборке нет. Длинные ожидания ускорены, это подписано в кадре.

Что показано:
1. Импорт 20-минутного подкаста через системный выбор файла. Записи встают в очередь и обрабатываются в фоне.
2. Экран обработки: этапы, время каждого, RTF, пик памяти (~300 МБ).
3. Готовая расшифровка: 20 минут аудио обработаны примерно за 5 минут (RTF 0.26), 2 спикера, время каждой реплики.
4. Воспроизведение с подсветкой текущего слова, переход к месту в аудио по тапу на реплику.
5. Переименование спикеров и «Запомнить голос».
6. Следующий выпуск подкаста: приложение само узнаёт ведущего по голосу.
7. Название и сводка от локальной LLM. Текст расшифровки она не меняет.
8. Поиск по расшифровке, экспорт в JSON по схеме ТЗ, TXT и SRT.
9. Настройки: режим, язык, число говорящих, база голосов со списком записей и прослушиванием.

Имена спикеров в видео латиницей, потому что ввод шёл через `adb`, а он не умеет кириллицу.
