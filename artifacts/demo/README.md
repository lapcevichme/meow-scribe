# Демонстрация

**Видео:** _ссылка будет добавлена_

Что показано в видео:
1. Импорт записи и обработка с прогрессом по стадиям.
2. Расшифровка: спикеры, время, плеер с подсветкой текущего слова, переход к реплике по нажатию.
3. Сводка от локальной LLM.
4. Поиск по расшифровке, переименование спикера, «Запомнить голос» и автоматическое узнавание в следующей записи.
5. Экспорт в JSON.
